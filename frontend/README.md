# SafePass-NER // Frontend UI Layer

This directory contains the user interface, interactive GIS maps, telemetry HUD, audio synthesis, and Progressive Web App service worker.

## Structure
- `index.html`: Main tactical navigation & emergency telemetry dashboard.
- `login.html`: User authentication and session management.
- `signup.html`: New user registration with emergency contact onboarding.
- `script.js`: Core client-side GIS routing, multi-hazard scoring, 1-Click SOS protocol, and 11 regional languages TTS.
- `style.css`: High-contrast dark and light mode stylesheet, custom HUD gauges, and segment risk indicators.
- `sw.js`: Service Worker caching assets for 100% offline navigation in mountain valleys.
- `lib/`: MapLibre GL GIS and Lucide icons client libraries.
- `assets/`: Media assets and official logos.
